# Body Condition

**In one line:** body condition is an animal's energy or nutritional state, usually measured as body mass adjusted for structural size, and it affects survival and reproduction.

> [!info] Before this, it helps to know
> [[Body Size|Body Size and Morphology]] · [[Linear Regression|Regression]]

## Start from zero
1. **Mass alone mixes size and condition;** a big bird can be heavy but lean.
2. **Condition indices** use residuals of mass on a size measure, or a scaled mass index; each has assumptions.
3. **In models,** put mass and a size measure together rather than using a ratio, which can mislead.
4. **Shipley et al. (2022):** male tree swallow breeding mass fell by 4% while female mass did not change, possibly because lighter females raise fewer offspring.
5. **Repeated within individuals,** so mixed models with individual ID are standard.

## In the course

## Common confusions
- **"Mass divided by length is a clean condition index."** Ratios can introduce spurious correlations with size.
