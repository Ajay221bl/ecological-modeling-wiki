# MOC 07 - Likelihood and Estimation

Unit 4 (Sep 1, 3): how a model's numbers are learned from data. Likelihood, maximum likelihood, confidence intervals, tests and p-values. Readings: Hobbs and Hooten 2015 Ch4, Powell and Gale 2015 Ch3.

## 1. Likelihood
- [[Likelihood]]: The likelihood of a parameter value is the probability (or probability density) of the observed data computed as if that parameter value were true.
- [[Likelihood Function]]: The likelihood function is the curve you get by computing the likelihood at every possible value of a parameter while the data stay fixed.
- [[Log-likelihood]]: The log-likelihood is the natural logarithm of the likelihood, used because it turns a product of many tiny probabilities into a manageable sum.
- [[Negative Log-likelihood]]: The negative log-likelihood is the log-likelihood with its sign flipped, so that the best parameter values are found at its lowest point.
- [[Maximum Likelihood Estimation]]: Maximum likelihood estimation chooses, as the estimate of a parameter, the value that makes the observed data more probable than any other value would.

- [[Likelihood Profile]]: A likelihood profile shows how well each value of one parameter can be supported when all the other parameters are re-optimised to do their best at that value.
- [[Likelihood Ratio]]: A likelihood ratio is the likelihood under one parameter value or model divided by the likelihood under another, measuring how much better the first...
- [[Nested Models]]: Two models are nested when the simpler one can be obtained from the more complex one by fixing some of its parameters, usually at zero.

- [[Likelihood Principle]]: The likelihood principle states that all the information the data hold about a model's parameters is contained in the likelihood function.

## 3. Hypothesis tests
- [[Null Hypothesis]]: The null hypothesis is the specific claim a test sets up to be challenged by the data, usually that an effect or difference is exactly zero.
- [[Alternative Hypothesis]]: The alternative hypothesis is the claim that holds if the null hypothesis is false, usually that the effect is not zero.
- [[Test Statistic]]: A test statistic is a single number computed from the data that measures how far the data are from what the null hypothesis predicts.
- [[P-value]]: A p-value is the probability, calculated assuming the null hypothesis is true, of getting a test statistic at least as extreme as the one actually observed.
- [[Significance Level]]: The significance level is the cut-off, chosen before the analysis, below which a p-value leads you to reject the null hypothesis.

- [[Type II Error]]: A Type II error is failing to reject a null hypothesis that is actually false: missing an effect that is really there.
- [[Statistical Power]]: Statistical power is the probability that a study will detect an effect of a given size when that effect really exists.
