# One Idea per Paragraph

**In one line:** each paragraph should carry one message, usually introduced by its first sentence, so readers can follow the argument by reading first sentences alone.

> [!info] Before this, it helps to know
> [[Theme and Key Points]]

## The everyday picture
Rooms in a house. A kitchen has one purpose; if you also put a bed in it, visitors are confused about where they are.

## Start from zero
1. **McCarthy (Savage and Yeh 2019):** limit each paragraph to a single message; a single sentence can be a paragraph.
2. **Move from question to idea,** and sometimes to an answer; it is fine to leave a question open.
3. **First sentence states the point;** the rest supports it.
4. **Check:** read only the first sentence of every paragraph; it should read as a summary of the paper.
5. **In results,** one paragraph per question or model, in the order of the methods.

## Common confusions
- **"Long paragraphs look more scholarly."** They hide the point.
