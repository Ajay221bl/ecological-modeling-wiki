# Complementary Log-log Link

"Did you catch at least one fish?" Behind the yes/no sits a count. If the fish caught are Poisson with mean λ, the chance of none is e^(−λ), so the chance of at least one is p = 1 − e^(−λ) ([[Poisson Distribution]]). Turn that around and log(λ) = log(−log(1 − p)). The **complementary log-log link** (cloglog) is exactly that: cloglog(p) = log(−log(1 − p)), with inverse p = 1 − exp(−exp(η)). So the [[Linear Predictor|linear predictor]] behaves like the log of a hidden rate or abundance, and coefficients read like log-link coefficients for the hidden count.

Unlike the logit and probit it is asymmetric: it approaches 1 quickly and 0 slowly, so the cloglog of 0.1, 0.5 and 0.9 is not symmetric about 0.5, as the code below shows ([[Logit Link]]). The code then simulates Poisson abundance with log-mean −1 + 2x, records only presence or absence, and fits a [[Logistic Regression|binomial GLM]] with a cloglog link: it recovers the Poisson coefficients −1 and 2 from presence-absence alone.

It suits [[Presence-Absence Data]] generated by abundance, and discrete-time survival. Because η is on the log-abundance scale, an [[Offset]] of log(effort) enters as it would in a Poisson model, which is useful when [[Sampling Effort|survey effort]] varies ([[Zuur et al. 2009 Ch10]], [[Probit Link]]). Do not confuse it with the log-log link, a different, mirror-image link.

```r
p <- c(0.1, 0.5, 0.9); log(-log(1 - p)); qlogis(p)                 # not symmetric about 0.5
set.seed(10); x <- runif(2000); lam <- exp(-1 + 2 * x); pres <- as.numeric(rpois(2000, lam) > 0)
coef(glm(pres ~ x, family = binomial("cloglog")))                  # recovers the Poisson coefficients -1 and 2 from presence-absence alone
```
