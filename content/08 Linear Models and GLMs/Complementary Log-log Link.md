# Complementary Log-log Link

**In one line:** the complementary log-log link is an asymmetric link for probabilities, log(−log(1 − p)), that arises when a yes/no outcome records whether a count is above zero.

> [!info] Before this, it helps to know
> [[Logit Link]] (the symmetric alternative) · [[Poisson Distribution]] (its origin) · [[Presence-Absence Data]] (its natural use)

## The everyday picture
"Did you catch at least one fish?" Behind the yes/no sits a count. If fish caught are Poisson with mean λ, the chance of "none" is e^(−λ), so the chance of "at least one" is 1 − e^(−λ). Turn that around and log(λ) = log(−log(1 − p)). The cloglog link recovers the log of the hidden abundance.

## Start from zero
1. **cloglog(p) = log(−log(1 − p)).**
2. **Inverse: p = 1 − exp(−exp(η)).**
3. **Asymmetric:** it approaches 1 quickly and 0 slowly, unlike logit and probit.
4. **η behaves like the log of an underlying rate or abundance.** So coefficients read like log-link coefficients for the hidden count.
5. **An offset works naturally:** log(effort) enters as it would in a Poisson model. Useful when survey effort varies.
6. **Use it for** presence-absence generated by abundance, and for discrete-time survival.

## In R
```r
p <- c(0.1, 0.5, 0.9); log(-log(1 - p)); qlogis(p)                 # not symmetric about 0.5
set.seed(10); x <- runif(2000); lam <- exp(-1 + 2 * x); pres <- as.numeric(rpois(2000, lam) > 0)
coef(glm(pres ~ x, family = binomial("cloglog")))                  # recovers the Poisson coefficients -1 and 2 from presence-absence alone
```
