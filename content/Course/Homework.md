# Homework

There are five homework problems, 5 points each (25 in total). Each one usually asks me to analyse a provided dataset in R and interpret the results in writing.

## How they are graded
1. **Clean, reproducible R code.** Dr. Roberts must be able to run it from start to finish without errors. Each error he has to fix costs 0.5 points, up to 1 point. *Why this matters:* it is the same standard as the project code, so the habits in [[MOC 03 - R for Ecological Modeling|MOC - R for Ecological Modeling]] (an [[RProject]], [[here()]], no `setwd()`) pay off twice.
2. **Reasoning** behind the coding and modeling choices. Say *why* you picked a distribution, a random effect or a selection method. The molecular notes in [[MOC 20 - Why We Do It This Way|MOC - Why We Do It This Way]] are written for exactly this.
3. **Support for the written conclusions** from the model results.
